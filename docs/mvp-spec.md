# InsightHub MVP Specification

## Product Idea

InsightHub is a multi-tenant product analytics platform for SaaS teams.
It helps founders, product managers, and engineering teams understand how users move through a product by tracking custom events, analyzing onboarding funnels, and monitoring feature adoption.

## Target Users

- SaaS founders who need quick product metrics without building internal analytics.
- Product managers who need funnels, activation metrics, and retention insights.
- Fullstack/product teams who want a lightweight event tracking API and dashboard.

## MVP Features

- Authentication with registration, login, and protected routes.
- Organizations with `owner` and `member` roles.
- Projects with API keys and timezone settings.
- Event ingestion API for product events.
- Dashboard with total events, unique users, top events, and activity stream.
- Funnels with 2-5 ordered event steps and conversion metrics.
- Demo data for local portfolio presentation.
